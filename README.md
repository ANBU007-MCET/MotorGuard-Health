# MotorGuard Health ⚙️

### AI-Based Motor Health Trend Predictor

MotorGuard Health is a Python-based machine learning dashboard that predicts motor temperature using operating hours, motor load, and ambient temperature.

## Features

- Motor temperature prediction using Linear Regression
- Interactive motor operating condition controls
- Temperature-based warning indicator
- Temperature trend visualization
- Model evaluation using MAE, RMSE, and R²
- Dataset preview and CSV downloads

## Technologies Used

- Python
- Streamlit
- Pandas and NumPy
- Matplotlib
- Scikit-learn

## How to Run Locally

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

## Dataset

The current version uses synthetic demonstration data generated by Python.

## Limitations

This is an educational prototype. It predicts temperature and does not diagnose actual motor faults. Real-world deployment requires appropriate sensor data, validation, and manufacturer-specific operating limits.
